# Urbanova

### Climate-Smart Engineering Decision Support Platform

> Turning 2D blueprints into data-driven, climate-resilient engineering decisions.

## Overview

URBANOVA helps architects, engineers, and developers evaluate environmental performance during the early design stage.

The platform transforms 2D CAD blueprints into environmental insights, scenario comparisons, and cost-linked engineering decisions.

## Key Features

* **2D CAD Ingestion** — Automated building geometry extraction from DWG/DXF.
* **Environmental Heatmaps** — Visualize thermal performance directly on the blueprint.
* **Scenario Comparison** — Compare different design and climate interventions.
* **Cost-Impact Analysis** — Connect environmental improvements with estimated implementation costs.
* **Decision Reports** — Generate clear, client-ready environmental analysis reports.

## Workflow

**2D Blueprint → Geometry Extraction → Environmental Analysis → Scenario Comparison → Decision Support**
